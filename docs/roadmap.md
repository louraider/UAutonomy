# Дорожня карта

Код пишуть агенти, тож строки рахуємо в днях; календар визначають людські та платформні кроки.

| Етап | Що | Орієнтир |
|---|---|---|
| 0 | Каркас репозиторію, CI для Android і Windows | тиждень 1 |
| 0 | Дослідження потреб (опитування, 200–300 реальних запитань) | тижні 1–2 |
| 1 | Перша APK і Windows-збірка: термінові картки, офлайн-пошук | кінець тижня 1 |
| 2 | ZIM-довідники (libzim), пакети контенту з перевіркою SHA-256 | тижні 2–3 |
| 3 | Офлайн-карти OSM / PMTiles без критичної інфраструктури | тижні 2–4 |
| 4 | Локальний ШІ: Gemma 4 E2B/E4B через llamadart, RAG з джерелами; порівняння з MamayLM/Lapa | тижні 3–5 |
| 5 | Обмін телефон-телефон і Wi-Fi-сервер з QR-кодом; headless-хаб | тижні 3–5 |
| 6 | Рецензія медиків і саперів, закритий тест Google Play (14 днів, 12+ тестувальників), підпис SignPath | тижні 3–6 |
| 7 | Публічна бета Android + Windows | ~тижні 5–6 |
| 8 | iOS (App Store) | ~тижні 7–8 |

## Що блокує реліз

- рецензія медичного вмісту та мінної безпеки;
- дозвіл IFRC / Червоного Хреста на їхні матеріали;
- схвалення SignPath Foundation;
- тести на реальних бюджетних телефонах.
