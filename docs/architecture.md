# Архітектура

```
app/                Flutter-інтерфейс (Android, Windows; iOS згодом)
  rust/             crate-міст для flutter_rust_bridge (лише перетворення типів)
  rust_builder/     cargokit: збирає Rust під кожну платформу разом із Flutter
core/               Cargo workspace
  crates/uautonomy-core   уся логіка, без залежності від UI
  crates/uautonomy-hub    headless-сервер для Raspberry Pi та ПК
docs/               план, дорожня карта, архітектура
```

## Принципи

1. **Логіка в Rust, інтерфейс у Flutter.** Ядро однакове для застосунку і для хаба.
2. **Офлайн за замовчуванням.** Мережа потрібна лише для завантаження пакетів, і кожен пакет перевіряється за SHA-256.
3. **Безпека вмісту.** Картка має поле `reviewed`; неперевірений вміст позначається в інтерфейсі.
4. **Слабкі пристрої.** Орієнтир: бюджетний Android із 3–4 ГБ ОЗП. ШІ необов'язковий і вмикається, лише якщо пристрій тягне.

## Модулі ядра

| Модуль | Що робить | Технологія |
|---|---|---|
| `card`, `content` | картки й статті з `content/`, вміст пакетів | serde |
| `zim` | читання довідників Kiwix | власний читач ZIM на Rust (zstd, xz), без C++ libzim |
| `search`, `text` | офлайн-пошук | BM25 + грубий український стемінг; ZIM — за заголовками |
| `pack`, `store`, `download` | пакети, SHA-256 кожного файлу, докачка, імпорт з USB | ureq (rustls), tar |
| `hardware`, `models` | ОЗП, ядра, диск; вибір моделі з каталогу | sysinfo |
| `rag` | запит до моделі з пронумерованими джерелами | — |
| `regions` | області для пакетів карт | — |
| `share` | Wi-Fi-сервер лише для читання: пошук, картки, ZIM, пакети, APK | tiny_http |

Модель ШІ працює в застосунку через llamadart (GGUF / LiteRT-LM). Ядро
лише підбирає фрагменти й складає запит, тому модель змінна: Gemma 4,
MamayLM, Lapa або будь-який файл, доданий кнопкою «Вибрати файл моделі».

## Застосунок

Вкладки: «Довідка» (картки й пошук), «Помічник» (локальний ШІ з
джерелами), «Карти» (PMTiles області, без інтернет-тайлів), «Пакети»
(залізо, рекомендації, завантаження, імпорт), «Обмін» (Wi-Fi-сервер і
QR-код). Подробиці форматів — у [packs.md](packs.md).
