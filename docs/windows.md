# Windows: інсталятор

Звичайним людям роздаємо один файл `avtonomiia-windows-setup.exe`
(посилання https://uautonomy.app/windows). ZIP-архів лишається для тих, хто
хоче запускати без встановлення (https://uautonomy.app/windows-zip).

## Що робить інсталятор

- Ставить «Автономію» для поточного користувача в
  `%LOCALAPPDATA%\Programs\Avtonomiia`, **без прав адміністратора** і без
  запитання UAC.
- Створює ярлик у меню «Пуск» і (галочка за замовчуванням) на робочому столі,
  запис «Автономія» в «Програмах та компонентах».
- Інтерфейс інсталятора українською (стандартний переклад Inno Setup).
- Новіший інсталятор оновлює застосунок на місці; якщо «Автономія» відкрита,
  пропонує її закрити.
- Під час видалення питає, чи стерти й завантажені пакети
  (`%APPDATA%\org.uautonomy`: карти, енциклопедії, моделі ШІ). За
  замовчуванням «Ні», бо без інтернету їх не завантажити знову. Тихе видалення
  (`/VERYSILENT`) дані не чіпає.
- Правило брандмауера для «Обміну» інсталятор не створює: його додає сам
  застосунок одним запитом UAC, коли людина вмикає обмін. Після видалення
  правило лишається (воно стосується лише шляху до `uautonomy.exe`).

Бібліотеки Visual C++ (`vcruntime140.dll`, `msvcp140.dll` тощо) лежать поруч
із `uautonomy.exe` (див. `app/windows/CMakeLists.txt`), тож окремо ставити
Visual C++ Redistributable не треба.

## Збірка

Сценарій: `app/windows/installer/avtonomiia.iss` (Inno Setup 6). CI збирає
його в задачі «Windows», тихо встановлює на чистому раннері, перевіряє файли,
ярлики й запис у реєстрі, запускає застосунок на 20 секунд і видаляє. Після
злиття в `main` інсталятор потрапляє в реліз `app`.

Локально, після `flutter build windows --release` у `app/`:

```powershell
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" /DAppVersion=0.1.0.1 windows\installer\avtonomiia.iss
# результат: app\build\installer\avtonomiia-windows-setup.exe
```

## Підпис

Поки інсталятор не підписаний, тож SmartScreen показує попередження
(«Докладніше» → «Однаково запустити»). Коли SignPath Foundation схвалить
проєкт, підписувати треба і `uautonomy.exe`, і сам інсталятор.
