# UAutonomy — «Автономія»

**Офлайн-бібліотека виживання для України.** Застосунок, який працює без інтернету і без світла в мережі: домедична допомога, цивільний захист, мінна безпека, офлайн-карти та локальний ШІ-помічник, що відповідає українською просто на телефоні чи комп'ютері.

> ⚠️ Проєкт на ранній стадії. Медичні матеріали та матеріали з мінної безпеки публікуються лише після перевірки фахівцями. У разі небезпеки телефонуйте **112** / **101** / **103**.

## Що буде всередині

- **Термінові картки «що робити зараз»** одразу після встановлення, без завантажень: кровотеча, опіки, обстріл, блекаут, вода, тепло.
- **Довідники**: Наказ МОЗ №441 (домедична допомога), матеріали ДСНС, IFRC First Aid Guidelines 2025.
- **Офлайн-карти** на основі OpenStreetMap (лише споживання даних, без редагування мапи України).
- **Локальний ШІ** (Gemma 4 E2B/E4B; MamayLM і Lapa на тестуванні), який відповідає з опорою на бібліотеку і показує джерело.
- **Поширення без інтернету**: з телефона на телефон і через локальний Wi-Fi-сервер (вхід за QR-кодом).

## Платформи

Спершу **Android** і **Windows** одночасно, потім **iOS**. Окремо буде headless-хаб для Raspberry Pi та домашніх серверів.

## Як влаштовано

| Частина | Технологія |
|---|---|
| Інтерфейс | Flutter (`app/`) |
| Ядро | Rust (`core/`), підключене через `flutter_rust_bridge` |
| ШІ | llama.cpp / LiteRT-LM через `llamadart` |
| Тексти | ZIM (libzim) |
| Карти | OSM, PMTiles |
