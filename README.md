# UAutonomy — «Автономія»

**Офлайн-бібліотека виживання для України.** Застосунок працює без інтернету і без світла: домедична допомога, цивільний захист, мінна безпека, офлайн-карти і ШІ-помічник, який відповідає українською просто на телефоні чи комп'ютері.

Сайт і завантаження: [uautonomy.app](https://uautonomy.app).

> **Рання тестова версія.** Медичні картки звірено з наказом МОЗ № 441, але їх ще не перевірив лікар, а картки з мінної безпеки ще не перевірив сапер. Застосунок показує це на кожній такій картці. У небезпеці телефонуйте **112** (103 швидка, 101 ДСНС).

## Що всередині

- **Термінові картки «що робити зараз»** доступні одразу після встановлення: кровотеча, опіки, обстріл, укриття, міни, блекаут, вода, тепло. Медичні картки складено за наказом МОЗ № 441, під кроками є дослівний текст наказу.
- **Енциклопедії** з Kiwix: українська Вікіпедія, її розділ «Медицина», медична енциклопедія WikiProject Medicine (англ.).
- **Офлайн-карти** всіх областей на основі OpenStreetMap.
- **ШІ-помічник на пристрої**: на телефоні Gemma 4 E2B, на ПК MamayLM 12B або Gemma 4 E4B для слабших машин. Відповідає за матеріалами бібліотеки і показує джерело. На медичні питання показує картки, а не переказує своїми словами.
- **Обмін без інтернету**: застосунок і пакети можна передати іншому пристрою через локальний Wi-Fi, вхід за QR-кодом.

## Платформи

Зараз **Android** і **Windows**. **iOS** у роботі (див. [docs/ios.md](docs/ios.md)). Окремо є headless-хаб для Raspberry Pi та домашніх серверів (`core/crates/uautonomy-hub`).

## Як влаштовано

| Частина | Технологія |
|---|---|
| Інтерфейс | Flutter (`app/`) |
| Ядро | Rust (`core/`), підключене через `flutter_rust_bridge` |
| ШІ | llama.cpp через `llamadart`, моделі GGUF |
| Довідники | ZIM, власний читач на Rust |
| Карти | OSM, PMTiles |

Докладніше: [docs/](docs/).
