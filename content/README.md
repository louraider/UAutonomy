# Вміст бібліотеки

Тут лежить текст, який застосунок показує людям: термінові картки «що робити зараз» і довідкові статті. Кожен фрагмент має джерело, дату, правовий статус і позначку, чи потрібна рецензія фахівця.

```
content/
  sources.json          реєстр джерел: хто видав, дата, URL, правовий статус, ліцензія
  cards/<category>.json термінові картки (масив об'єктів)
  articles/<category>/  довідкові статті у Markdown з YAML-фронтматером
  COPYRIGHT.md          розбір авторського права (ст. 8 Закону № 2811-IX)
  REVIEW.md             що мають перевірити медик і сапер, і що ще не перенесено
```

## Картка

Сумісна з `uautonomy_core::Card`; додаткові поля ядро читає як необов'язкові.

| Поле | Обов'язкове | Що це |
|---|---|---|
| `id` | так | унікальний у всьому `content/`; префікс `fa-`, `cp-`, `ms-`, `hh-` |
| `category` | так | `first_aid`, `civil_protection`, `mine_safety`, `household`, `communication` |
| `title` | так | назва так, як її шукає людина |
| `summary` | так | одне-два речення: головна дія |
| `steps` | так | кроки, по одній дії |
| `warnings` | ні | чого не робити |
| `source` | так | назва джерела для людини |
| `source_ids` | так | id з `sources.json` |
| `source_ref` | так | пункт джерела, напр. «Порядок 4, п. 4» |
| `source_quote` | ні | дослівний текст пунктів офіційного акта (лише для актів, які можна цитувати, як наказ МОЗ № 441); блоки «[Порядок N]», абзаци через порожній рядок |
| `source_quote_ref` | ні | які пункти наведено в `source_quote`, напр. `["P4:3", "P4:4"]` |
| `source_url` | ні | посилання на оригінал для людини |
| `editorial_notes` | ні | що додала редакція понад джерело (рецензент перевіряє саме це) |
| `tags` | ні | слова, якими люди шукають |
| `review_required` | так | `medic`, `deminer` або `null` |
| `reviewed` | так | `false`, доки фахівець не підписав |
| `updated` | так | дата останньої зміни |

## Стаття

```markdown
---
id: art-...
title: ...
category: first_aid
source_ids: [moz-441]
review_required: medic
reviewed: false
updated: 2026-11-22
---
# Заголовок
Текст...
```

## Правила

1. **Своїми словами.** Ми переказуємо факти і порядок дій простою мовою. Дослівно можна брати лише офіційні документи (див. COPYRIGHT.md).
2. **Кожна дія має джерело.** Те, чого немає в джерелі, записується в `editorial_notes`.
3. **Медичне і мінна безпека** (`first_aid`, `mine_safety`, а також окремі картки інших розділів) мають `review_required` і не виходять у публічний реліз без підпису фахівця.
4. **Не вигадуємо цифр.** Дози, хвилини, сантиметри беремо лише з джерела.
5. **Жодних інструкцій зі знешкодження** вибухових предметів, виготовлення зброї чи вибухівки.

Перевірка формату: `python tools/validate_content.py`.
